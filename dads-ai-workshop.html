from flask import Flask, request, jsonify, render_template_string
import requests

app = Flask(__name__)
HTML = """
<!DOCTYPE html><html><head><title>DadAI</title>
<style>body{font-family:sans-serif;max-width:600px;margin:40px auto;padding:20px}
input{width:80%;padding:8px}
button{padding:8px 16px;background:#2c3e50;color:white;border:none;cursor:pointer}
#chat{margin-top:20px;white-space:pre-wrap}</style></head>
<body><h2>DadAI — Built for All Fathers</h2>
<input id="q" placeholder="Ask DadAI anything..."/>
<button onclick="ask()">Send</button>
<div id="chat"></div>
<script>
async function ask(){
  const q=document.getElementById('q').value;
  const res=await fetch('/chat',{method:'POST',
    headers:{'Content-Type':'application/json'},
    body:JSON.stringify({message:q})});
  const data=await res.json();
  document.getElementById('chat').innerText+=
    'You: '+q+'\\nDadAI: '+data.response+'\\n\\n';
  document.getElementById('q').value='';
}
</script></body></html>"""

@app.route('/')
def home(): return render_template_string(HTML)

@app.route('/chat', methods=['POST'])
def chat():
    msg = request.json.get('message','')
    resp = requests.post('http://localhost:11434/api/generate',
        json={"model":"DadAI","prompt":msg,"stream":False})
    return jsonify({'response':resp.json().get('response','No response')})

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000)

1

Physical Kill Switches — Mic & Camera

A kill switch is a physical button wired inline that cuts power to a device entirely. When it's off, no software in the world can activate it — not malware, not a remote command, nothing.

Inline USB Kill Switch
~$8 each
Plugs between your USB mic and the Pi. One button physically cuts the mic's power circuit. Search "USB power switch inline" on Amazon.
Camera Module Kill Switch
~$5
A small slide switch wired to the camera ribbon cable's power line. Physically disconnects the camera. Or simply: don't attach a camera at all.

DIY kill switch wiring (mic):

# No software needed — this is purely physical:
# USB cable: cut the red (power) wire
# Insert a toggle switch inline on the red wire
# When switch is OFF, mic has zero power
# When switch is ON, mic works normally
🔒A physical switch cannot be overridden by software. This is more secure than any app-based mute button.
2

WiFi Isolation — Go Fully Offline

Once your AI model is downloaded, DadAI never needs the internet again. Disabling WiFi entirely is the strongest privacy measure you can take.

Disable WiFi in software:

sudo rfkill block wifi
# To re-enable temporarily for updates:
sudo rfkill unblock wifi

Block WiFi permanently at boot (add to /etc/rc.local):

sudo nano /etc/rc.local
# Add this line before "exit 0":
rfkill block wifi
USB WiFi Dongle with Physical Switch
~$12
Some USB WiFi adapters have a physical on/off switch. Use one as your only WiFi connection — flip it off after setup. Leaves the Pi's internal radio disabled.
Faraday Pouch (Tablet Size)
~$15
Stores the Pi when not in use. Blocks all RF signals — WiFi, Bluetooth, cellular. Useful for transport between events.
3

Encrypted Storage — Hardware Security Key

Encrypting your MicroSD means that even if someone physically takes the card, they cannot read any data without your key.

Set up full-disk encryption during OS setup:

# During Raspberry Pi Imager setup, enable:
# "Set username and password" — use a strong password
# This password protects the boot partition

# After first boot, encrypt your home folder:
sudo apt install ecryptfs-utils -y
sudo ecryptfs-migrate-home -u pi
YubiKey 5 NFC
~$50
A physical USB security key. Plug it in to unlock the Pi. Remove it and the system locks. Without the key, encrypted data is unreadable.
OnlyKey (open source alternative)
~$48
Open-source hardware key with PIN entry directly on the device. No software needed to use it. Great for community deployments.

Configure YubiKey for Pi login:

sudo apt install libpam-yubico -y
sudo nano /etc/pam.d/common-auth
# Add this line at the top:
auth required pam_yubico.so id=YOUR_CLIENT_ID
🔒With a hardware key, even someone who knows your password cannot log in without the physical device in hand.
4

Disable Bluetooth & Lock the Boot

Two final steps that close the remaining exposure points.

Disable Bluetooth permanently:

sudo nano /boot/config.txt
# Add this line at the bottom:
dtoverlay=disable-bt
sudo systemctl disable bluetooth.service
sudo rfkill block bluetooth

Lock the bootloader (prevents USB boot attacks):

sudo raspi-config
# Navigate to: Advanced Options → Bootloader Version
# Select: "Latest" then set boot order to SD card only
# This prevents someone from booting from a USB drive
# to bypass your encryption
🔒With Bluetooth disabled and the bootloader locked, there is no wireless attack surface and no way to bypass storage encryption via USB boot.

Feature 1 — Face Recognition

Automatically identify returning fathers so DadAI can greet them by name and pull up their previous session context.

nano ~/dadai_faceid.py
File: ~/dadai_faceid.py
import face_recognition, cv2, pickle, os
from picamera2 import Picamera2

# Load saved face encodings (built over time)
ENCODINGS_FILE = os.path.expanduser("~/face_encodings.pkl")

def load_known_faces():
    if os.path.exists(ENCODINGS_FILE):
        with open(ENCODINGS_FILE, "rb") as f:
            return pickle.load(f)
    return {"encodings": [], "names": []}

def save_face(name, image_path):
    """Register a new father's face."""
    data = load_known_faces()
    img = face_recognition.load_image_file(image_path)
    encodings = face_recognition.face_encodings(img)
    if encodings:
        data["encodings"].append(encodings[0])
        data["names"].append(name)
        with open(ENCODINGS_FILE, "wb") as f:
            pickle.dump(data, f)
        print(f"Registered: {name}")

def recognize_live():
    """Run live face recognition from camera."""
    data = load_known_faces()
    cam = Picamera2()
    cam.start()
    print("Camera ready. Press Q to quit.")
    while True:
        frame = cam.capture_array()
        rgb = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
        boxes = face_recognition.face_locations(rgb)
        encodings = face_recognition.face_encodings(rgb, boxes)
        for encoding, box in zip(encodings, boxes):
            matches = face_recognition.compare_faces(
                data["encodings"], encoding, tolerance=0.5)
            name = "Unknown Father"
            if True in matches:
                idx = matches.index(True)
                name = data["names"][idx]
            print(f"Recognized: {name}")
            top, right, bottom, left = box
            cv2.rectangle(frame, (left, top), (right, bottom), (0, 200, 0), 2)
            cv2.putText(frame, name, (left, top - 10),
                cv2.FONT_HERSHEY_SIMPLEX, 0.7, (0, 200, 0), 2)
        cv2.imshow("DadAI Face ID", frame)
        if cv2.waitKey(1) & 0xFF == ord("q"):
            break
    cam.stop()
    cv2.destroyAllWindows()

if __name__ == "__main__":
    recognize_live()

To register a father's face (take a photo first, save as john.jpg):

python3 -c "from dadai_faceid import save_face; save_face('John', 'john.jpg')"

To run live recognition:

python3 ~/dadai_faceid.py
🔒Privacy note: All face encodings are stored locally in ~/face_encodings.pkl on the Pi. No face data ever leaves the device. Fathers can request deletion of their encoding at any time.

Feature 2 — Document Scanning

nano ~/dadai_scan.py
File: ~/dadai_scan.py
import pytesseract, requests, cv2
from picamera2 import Picamera2
from PIL import Image
import numpy as np

def scan_and_ask(question="Summarize this document and explain what I need to do."):
    """Capture document from camera, OCR it, send to DadAI."""
    cam = Picamera2()
    cam.configure(cam.create_still_configuration(
        main={"size": (3000, 2000)}))  # High res for documents
    cam.start()
    print("Hold document flat in front of camera. Press ENTER to scan...")
    input()
    frame = cam.capture_array()
    cam.stop()

    # Convert and run OCR
    img = Image.fromarray(frame)
    text = pytesseract.image_to_string(img)
    print(f"Scanned text ({len(text)} chars). Sending to DadAI...")

    # Send to local DadAI
    prompt = f"Document text:\n{text}\n\nQuestion: {question}"
    resp = requests.post("http://localhost:11434/api/generate",
        json={"model": "DadAI", "prompt": prompt, "stream": False})
    answer = resp.json().get("response", "No response")
    print(f"\nDadAI says:\n{answer}")
    return answer

if __name__ == "__main__":
    q = input("What would you like to know about this document? ") or         "Summarize this and tell me what action I need to take."
    scan_and_ask(q)

The Case for Investment
Why Fund This. Why Now.

This Is Infrastructure, Not a Program

Most grants fund a service that exists as long as the money does. Dads & Data is different. Every dollar spent on hardware creates a permanent asset owned by the father. When the grant period ends, 77 fathers still have their DadAI. The coalition still has its network. The intake reform question is still being asked. Nothing disappears because the funding cycle closed.

🏠 Housing & Family Stability

All fathers — custodial, married, or co-parenting — face housing questions tied to their family situation. DadAI knows the intake systems and helps every father navigate them — at 2am, offline, in their own home.

🧠 Therapy & Education First

DadAI centers therapy access, mental health resources, and education advocacy — for fathers and their children. A father who knows how to navigate an IEP or find affordable therapy is a father who changes outcomes.

💻 Technology Access

Low-income fathers are priced out of AI tools that cost $20–$200/month. A one-time $522 hardware investment gives a father everything those subscriptions provide — privately, permanently.

📋 Replicable Model

The workshop curriculum, Modelfile, and code are open. Any city, any coalition, any fatherhood organization can replicate this. You're not just funding Atlanta — you're funding a national template.

The Question That Changes Everything

In partnership with the City of Atlanta Mayor's Office, this coalition is introducing one question into every service provider intake form citywide: "Are you a custodial, married, co-parenting, or active father?" That question costs nothing to add. But it makes all fathers visible in housing, education, therapy, and social service data for the first time. Funder dollars directly accelerate a policy change with citywide — and potentially national — reach.

Coalition Delivering This Work

Family Outreach Ministries Int. Inc. — Lead coalition partner & community anchor. The faith-rooted relational network through which fathers are reached and trusted.

FadoCare — Father-centered care and wellness. Bridges physical wellbeing with long-term family stability.

UN-HID (Unraveling Housing Insecurities for Dads) — Organizing body. Coordinates the intake reform effort and citywide partnership with Atlanta Mayor's Office.

Fathers MATTER Atl — Weekly Fathers Day events, peer support, and community engagement across the Atlanta metro area.
